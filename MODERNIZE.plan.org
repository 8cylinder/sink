* Overview
  Review of the =sink= codebase (~3,100 LOC, 14 modules) to move it onto
  modern Python (>=3.13), add complete type hints, harden security, and
  fix latent bugs.  This plan is the deliverable of the review; execution
  will follow separately.

  The dominant problems are structural rather than algorithmic:
  - A mutable global =config= singleton and an untyped =Dict2obj= wrapper
    used everywhere.
  - All remote work goes through =subprocess(... shell=True)= with
    f-string interpolation of config/user values, including passwords.
  - No tests, no CI, no lint/format/typecheck configuration.
  - Several modules are unreachable or crash-on-use (deploy, vm) because
    of signature drift.
  - Packaging still straddles a legacy =setup.py= and an untracked uv lock.

* Goals and non-goals
** Goals
   - Target Python >=3.13, single-sourced version, clean packaging.
   - Move dependency/venv/build management from Poetry to uv.
   - Full type coverage checked by =ty=; Ruff lint+format enforced.
   - Replace shell string building with a typed command-execution layer.
   - Remove secrets from command lines, logs, and process tables.
   - Fix the crash/incorrect-behavior bugs catalogued below.
   - Build a real test suite and CI.
** Non-goals
   - Rewriting every command into a new UX; behavior stays recognizable.
   - Removing the "dry-run by default / --real" model (it is core).
   - Windows support (remote servers and tooling remain Linux/macOS).

* Locked decisions
  | Decision       | Choice                                             |
  |----------------+----------------------------------------------------|
  | Python floor   | >=3.13 (runs on 3.14; this machine is 3.14-only)   |
  | Deps/venv/lock | uv (replaces Poetry)                               |
  | Build backend  | hatchling (proposed; poetry-core is low-churn alt) |
  | Lint/format    | Ruff (check + format)                              |
  | Type checker   | ty (Astral)                                        |
  | Tests          | pytest (+ pytest-cov), click CliRunner             |
  | Back-compat    | CLI and sink.yaml MAY change; migrate with tooling |

** WS2 Typed configuration layer                                      :config:
   The root smell is that one object is simultaneously the *data store*, the
   *loader*, and a *mutable global*.  Split those three roles, then inject
   the result explicitly.

*** Principle
    Separate /what the data is/ (model) from /how it is obtained/ (loader)
    from /who owns its lifecycle/ (composition root).  Load once at the CLI
    entrypoint and pass it down.  Consumers depend on the narrow slice they
    need, not the whole blob.

*** Models - =sink/config/models.py= (pure, no I/O, immutable)
    #+begin_src python
    @dataclass(frozen=True, slots=True)
    class SSHConfig:
        name: str | None
        username: str
        server: str
        key: Path | None
        port: int | None

    @dataclass(frozen=True, slots=True)
    class DatabaseConfig:
        db: str
        username: str
        password: str
        hostname: str | None = None
        port: int = 3306

    @dataclass(frozen=True, slots=True)
    class Server:
        name: str
        root: Path
        deploy_root: Path | None
        ssh: tuple[SSHConfig, ...]
        databases: tuple[DatabaseConfig, ...]
        urls: tuple[URLConfig, ...]
        actions: Mapping[str, str]

    @dataclass(frozen=True, slots=True)
    class Config:
        project: Project
        servers: Mapping[str, Server]
    #+end_src
    Frozen + slots + tuples/immutable mappings kills the =default_project=
    mutation bug (B5) by construction; use =dataclasses.replace()= when a
    variant is needed.

*** Loader - =sink/config/loader.py= (only module that touches disk)
    #+begin_src python
    def load(path: Path) -> Config:
        """Parse, validate, migrate. Raise ConfigError. No sys.exit, no cache."""
    #+end_src
    - [ ] Implement =load(path: Path) -> Config= as a pure function.
    - [ ] Validate explicitly and raise =ConfigError= (no =sys.exit= in the
          loader); keep =Configuration= as a temporary shim during migration.
    - [ ] Stop mutating class-level defaults: build fresh objects
          (=config.py:267=, =_server= at =config.py:356=).
    - [ ] Replace =Dict2obj= (=config.py:71=) with the dataclasses; delete
          the dead =to_dict= and =syncpoint= stubs.
    - [ ] Add =Config.resolve_server(name) -> Server= (cached, raising on
          unknown) instead of re-reading =self.data= each call.

*** Composition root - =sink/cli/main.py=
    Own the one lifetime. A =Runtime= dataclass carries config plus run
    flags so there is a single cohesive dependency instead of several
    globals.
    #+begin_src python
    @dataclass(frozen=True, slots=True)
    class Runtime:
        config: Config
        real: bool = False
        log: logging.Logger = ...

    @click.pass_context
    def sink(ctx: click.Context) -> None:
        ctx.obj = Runtime(config=load(find_config()))
    #+end_src
    - [ ] Pass =Runtime= (or just =Config=) through =click.Context.obj=
          instead of the global singleton (gradual).
    - [ ] Make =get_servers= completion (=sink/sink.py:52=) read from
          =ctx.obj=, not reload config on every keystroke.

*** Consumption rules
    - Inject via =ctx.obj= only as the composition root; do not re-export it
      as a module global. Thread =Runtime= / =Config= / =Server= into pure
      functions and methods.
    - Prefer the narrow slice: =def pull(cfg: Config, server: Server, *,
      real: bool)=, not =def pull(cfg: Config)=.
    - Feature modules may import =sink.config.models= only; never
      =sink.config.loader= or the old global.
    - No import-time side effects: delete =config = Configuration()=
      (=config.py:486=). Instantiate in =main()=.

*** Singleton policy
    A global is acceptable *only if immutable and initialized without I/O*.
    If a single instance is unavoidable, expose a provider
    (=@lru_cache def get_config()=) that tests can override; never a mutable
    module-level object.

*** Testing
    - =tests/conftest.py= builds a =Config= fixture directly (or from a temp
      =sink.yaml= via =load()=) and injects it; no global reset, no
      monkeypatching of =sink.config=.
    - Keep one thin test that =load()= against a golden =sink.yaml= equals a
      hand-built =Config=.

*** Enforcement
    - [ ] Add =import-linter= (=[tool.importlinter]= in pyproject) with a
          layering contract: =sink.cli= -> =sink.config.models=;
          feature modules -> =sink.config.models=; nothing except
          =sink.cli= -> =sink.config.loader=.
    - [ ] Fail CI on contract violations.
